# 🇿🇦 Spaza_eCommerce_SA

> My first SA eCommerce project for spaza shops - built by StheB

A Python-based eCommerce solution designed specifically for South African spaza shops. Helping local township businesses go digital.

## 🚀 Features
- Product listing for spaza shop items
- Shopping cart functionality  
- Simple checkout system
- Built for local SA market

## 🛠️ Tech Stack
- Python
- GitHub
- SA Township eCommerce

## 📦 How to Run
1. Clone: `git clone https://github.com/StheBcoder/Spaza_eCommerce_SA-.git`
2. Run: `python spaza_shop.py`
